# Photoshap

Petit logiciel d'édition d'images basé sur Python.

## Description

Photoshap est une application simple pour l'édition d'images utilisant Python, Tkinter et Pillow. Elle permet d'importer des images, d'appliquer des filtres et des transformations de base.

## Fonctionnalités

- Importation d'images (PNG)
- Redimensionnement automatique à 512x512
- Transformations : négatif, rotation, demi-image, canal monochrome, etc.
- Aperçu des images
- Sauvegarde des images modifiées

## Installation

1. Assurez-vous d'avoir Python installé.
2. Installez les dépendances : `pip install pillow numpy`
3. Téléchargez le code source.
4. Exécutez `python interface.py`

## Utilisation

Lancez l'application et utilisez l'interface graphique pour importer et éditer des images.
